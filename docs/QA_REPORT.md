### 5,000핸드 선택 비중 (등장≠승률)

실버/저티어 후보가 자주 뜨는 구조상 `숫자 교정`·`운명 재배분`·`순서 조작`·`레이즈 제한` 선택 비중이 ~11%대로 높고, `패 뒤집기`·`미래 예지`·`심리 압박`은 ~1–1.4%로 낮음 (라운드1 전용·티어 가중 영향).

| 관찰 | 판단 |
|------|------|
| 고티어(복제/패뒤집기) 선택률 낮음 | 의도된 희귀도로 보이며 **자동 너프 미적용** |
| 실버 다수 선택 | 밸런스 붕괴 증거 아님 — 승률/기대수익 분리 측정 필요 |
| `rerollFate` picks=0 | 선택 화면 전용·`augmentPicked` 미기록 — 정상 |

**자동으로 증강 수치를 변경하지 않음.** (요청: 재미를 크게 바꾸는 수정은 보고만)
