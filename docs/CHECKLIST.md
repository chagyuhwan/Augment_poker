# AUGMENTED POKER 개발 체크리스트

표기: [x] 완료(테스트로 확인) · [~] 임시 구현(이후 단계에서 교체) · [ ] 미완료

## 실행 방법

| 목적 | 명령 |
| --- | --- |
| 개발 실행 (Vite + Electron) | `npm run electron:dev` |
| 같은 PC에서 두 번째 클라이언트 | `npm run electron:second` (개발 서버 실행 중일 때) |
| 단위 테스트 | `npm test` |
| UI 스모크 테스트 (3개 해상도, 스크린샷 `test-results/ui`) | `npm run dev` 실행 후 `npm run test:ui` |
| 타입 검사 + 프로덕션 빌드 | `npm run build` |
| Windows 빌드 | `npm run dist:win` |

로그와 설정 위치: `%APPDATA%\AUGMENTED POKER\logs`, `%APPDATA%\AUGMENTED POKER\settings.json`

## 게임머니 (계정 지갑)

- [x] 모든 모드가 같은 계정 게임머니를 사용, 게임을 꺼도 유지 (첫 실행 100,000 지급)
- [x] 테이블 머니 분리: 입장 시 계정에서 차감(바이인), 퇴장 시 남은 칩만 반환. 중복 증가 없음 (스모크: 100,000 − 6,000 + 남은 칩 = 잔액)
- [x] 요청 ID(opId) 중복 차단: 같은 요청을 다시 보내도 한 번만 반영 (단위 테스트)
- [x] 비정상 종료 복구: 판마다 체크포인트, 재실행 시 팟에 넣지 않은 칩만 반환 (단위 테스트)
- [x] 무료 충전: 보유(테이블 포함) 5,000 미만일 때 50,000, 하루 3회, 시계 되돌리기 거부, 내역 기록 (단위 테스트 + 스모크)
- [x] 게임머니 화면: 잔액, 테이블 금액, 충전 조건·남은 횟수·불가 사유, 내역, 환전·거래 불가 안내
- [x] 잔액 부족 시 방 찾기·봇 대전에서 충전 화면으로 안내
- [~] 저장소: Electron 메인 프로세스의 로컬 파일 + HMAC 서명 + 백업. **서명 키가 실행 파일 안에 있어 숙련자의 변조를 완전히 막을 수 없다.** 온라인 대전 전에는 서버 지갑으로 교체해야 한다
  - 교체 방법: `IWalletService`(`src/wallet/types.ts`)를 서버 API 구현으로 바꾼다. 같은 op 규칙(buyIn / cashOut / claimFree / checkpoint, opId 멱등)을 서버가 검증하고 정산 결과를 서버가 확정한다
- [~] 브라우저 개발 모드(`npm run dev`만 실행)는 localStorage 개발용 지갑을 쓴다. 게임 앱 잔액과 별개이며 보안 의미 없음
- [ ] 유료 충전: 설계만 (`src/wallet/purchase.ts`). Steam MicroTxn 연동 전에 확인할 것
  - 확률형/사행성 규정, 게임물 등급(포커류 게임머니 판매 시 등급·심의 영향), Steam 정책
  - 결제 한도, 청약 철회·환불, 미성년자 결제 보호, 영수증 서버 검증
